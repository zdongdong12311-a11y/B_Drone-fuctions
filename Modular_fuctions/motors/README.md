# Motors — 舵机 & 激光笔串口控制

基于 **Raspberry Pi Pico** 的三路标准舵机 + 激光笔控制方案。Pico 通过串口接收行模式指令（以 `\n` 结尾），驱动对应舵机转到指定角度或开关激光笔；上位机（电脑或开发板）运行 `test.py` 进行交互测试或单次发令。

## 项目结构

| 文件 | 运行环境 | 说明 |
|------|----------|------|
| `pico.py` | Raspberry Pi Pico（MicroPython） | 烧录进 Pico，负责串口监听、舵机角度控制与激光笔开关 |
| `test.py` | 电脑 / 开发板（Python 3） | 串口测试脚本，支持交互菜单或命令行单次发令 |

## 硬件连接

| Pico 引脚 | 功能 |
|-----------|------|
| GP0 | 舵机 0（红）PWM |
| GP1 | 舵机 1（蓝）PWM |
| GP2 | 舵机 2（绿）PWM |
| GP3 | 激光笔开关（高电平开启） |
| GP25 | 板载 LED（舵机动作时点亮） |
| USB | 与上位机串口通信（115200 波特率） |

舵机为 **标准 180° 舵机**，PWM 频率 50 Hz。

## 工作原理

```
test.py（上位机）
      ↓  串口 115200，行模式（命令 + \n）
pico.py（Pico）
      ↓  PWM / GPIO
舵机 0/1/2 + 激光笔
```

1. 上位机通过串口发送 ASCII 命令，**必须以换行符 `\n` 结尾**。
2. `pico.py` 解析命令后执行对应动作，并通过串口打印回显。
3. 舵机命令会先将对应舵机转到 150°，停留 5 秒后回到 0°。

## 串口指令

| 命令 | 发送内容 | 动作 |
|------|----------|------|
| `0` | `b'0\n'` | 舵机 0（红）→ 150°，停 5 s → 0° |
| `1` | `b'1\n'` | 舵机 1（蓝）→ 150°，停 5 s → 0° |
| `2` | `b'2\n'` | 舵机 2（绿）→ 150°，停 5 s → 0° |
| `3` | `b'3\n'` | 开启激光笔 |
| `4` | `b'4\n'` | 关闭激光笔 |

Pico 收到未知命令时会打印 `未知命令: ...`。

## Pico 端配置（pico.py）

主要可调参数：

```python
MIN_DUTY = 1638   # 0° 对应占空比
MAX_DUTY = 7864   # 180° 对应占空比
```

舵机动作流程中，目标角度与停留时间写死在各命令分支内（默认 150°、5 s）。可按需修改 `set_servo_angle()` 调用及 `time.sleep(5)` 的数值。

上电后激光笔默认关闭，LED 快闪 0.2 秒表示初始化完成。

## 使用方法

### 1. 烧录 Pico 固件

1. 在 Pico 上安装 [MicroPython](https://micropython.org/download/RPI_PICO/)。
2. 将 `pico.py` 重命名为 `main.py`（或通过 Thonny / rshell 等方式部署），使 Pico 上电自动运行。
3. USB 连接上位机，确认出现串口设备（Linux 下通常为 `/dev/ttyACM0`）。

### 2. 运行测试脚本

依赖：

- Python 3
- pyserial

```bash
pip install pyserial
```

**交互菜单模式：**

```bash
python test.py
```

**命令行单次发令：**

```bash
python test.py 0    # 触发舵机 0
python test.py 3    # 开启激光笔
python test.py 4    # 关闭激光笔
```

脚本会依次尝试 `PORT` 配置项及 `/dev/ttyACM0`、`/dev/ttyACM1`、`/dev/ttyUSB0`、`/dev/ttyUSB1`，波特率 **115200**。Windows 下请将 `test.py` 中的 `PORT` 改为 `COMx`。

### 3. 手动串口测试

不运行 `test.py` 时，可用任意串口工具发送带换行的命令：

```bash
# Linux 示例：触发舵机 0
echo -n "0" > /dev/ttyACM0

# 或使用 printf 显式发送换行
printf "3\n" > /dev/ttyACM0
```

## 注意事项

- 串口协议为**行模式**，命令必须带 `\n` 结尾，否则 Pico 不会响应。
- 舵机动作期间（约 5 秒）会阻塞主循环，此期间无法处理新命令。
- 确保舵机与激光模块供电充足；大电流建议独立供电，并与 Pico 共地。
- 激光笔使用时请注意安全，避免直射人眼。
- 修改 `MIN_DUTY` / `MAX_DUTY` 前请参照所用舵机规格，错误参数可能导致舵机抖动或不到位。
